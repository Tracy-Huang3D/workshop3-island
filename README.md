# Workshop 03 · 芽芽的林间秘密花园

一个供学员下载、运行和继续创作的 3D 小岛项目。使用 Vite + Three.js，包含芽芽、树、苔藓窝、灯笼、果篮、水碗、蘑菇、踏脚石和花草。

本地项目：`workshop3-island`，基于 Workshop 02 小岛继续开发。当前保留骨骼角色的原地代码待机；Step 05 已接入 WASD / 方向键移动、Shift 跑步、动作混合和镜头跟随；Step 06 第一部分加入代码空格跳跃。下方 Workshop 02 学习资料保留作为场景搭建参考。

## 快速开始

先安装支持 Vite 8 的 Node.js（20.19+ 或 22.12+；建议 Node.js 24），然后在项目文件夹中运行：

```sh
npm ci
npm run dev
```

打开终端显示的本地地址（默认 http://127.0.0.1:5173/）。拖动鼠标环绕观察、滚轮缩放，点击“重置视角”回到初始构图。若端口被占用，先停止占用该端口的服务再启动。

检查生产构建：

```sh
npm run build
npm run preview
```

模型体积较大，下载和首次加载需要时间。若模型加载失败，页面会保留占位形状并提示错误；占位形状不代表真实模型加载成功。

## 文件结构

- `index.html`：网页入口。
- `src/main.js`、`src/style.css`：小岛场景和界面。
- `public/models/`：网页实际加载的模型，必须保留。
- `models/`：原始模型素材，供跟做和替换参考。
- `draft png/`、`woodland_lantern.png`：概念图和参考图片。
- `woodland_lantern.glb`：灯笼原始素材。
- `docs/workshop02/`：学员教程和提示词。
- `docs/evidence/`：教程配套截图和演示 GIF；教学重演与历史截图不代表本次运行验证。
- `package.json`、`package-lock.json`：启动命令与锁定的依赖版本。

当前版本不包含课程策划案、内部制作记录和讲师录制脚本。`node_modules/`、`dist/`、个人进度记录和临时输出不会提交。

## 功能边界

目前支持场景展示、原地待机、WASD / 方向键移动、Shift 跑、环绕缩放、跟随与重置。现已支持空格跳跃，暂不包含边界或碰撞，走出岛和穿过物件属于当前范围；点击互动、声音和公开部署尚未实现。真实手机、Safari / Firefox、低端 GPU、限速网络及正式部署需要另外验证。

## Step 05 调节与验证

- `src/yaya-controller.js` 顶部：移动速度 0.64、转向速度 7、跑步倍率 1.6、混合时间 0.3 秒。
- `src/fox-walk.js` 的 `WALK_SPEED=0.8` 控制预设播放速度。移动速度按身高 2.25 的四脚低位后扫速度估算；各脚存在差异，不保证完全无滑步，需视觉微调。
- 原 `models/fox.glb` 保留；运行时加载它的副本 `public/models/yaya-rigged.glb`。尾部复用现有一条骨链，不假造三条独立骨链。
- 运行 `node tests/step05.mjs` 检查真实模型的操控逻辑，再运行 `npm run build`。
- 开发预览加 `?record=1` 可录制 16 秒真实画布；不会自动操作角色。正式构建不显示此入口。

## Step 06 第一部分：空格跳跃

- 按一次空格：0.12 秒蓄力 → 约 0.6 秒腾空（高度 0.6）→ 0.15 秒落地回弹。空中冻结腿部动作，落地恢复待机或行走。
- 空中 WASD 可转向，水平速度为地面的 0.8 倍；保留起跳时的跑步倍率。空中再次按空格不二段跳，按住不连跳，松开再按才能再次起跳。
- 镜头只跟随水平移动；重置可立即取消跳跃并回到起点。没有踏脚石落点；岛边界与碰撞见下一节。
- 所有跳跃调节项在 `src/yaya-controller.js` 顶部，含中文注释。
- `public/models/yaya-rigged.glb` 已包含在仓库中，随 Git 下载，无需另行补入绑定模型。原模型文件保留。
- `node tests/step06.mjs` 验证真实骨骼模型的高度、腾空时间、缩放底部补偿、动作冻结、防连跳、空中跑速与重置；`npm run build` 检查构建。
- 开发预览加 `?record=1&jump=1` 显示 11 秒画布录屏按钮，需实际键盘操作。正式构建不显示入口。录屏不包含键盘按键提示，不能单凭视频证明按键时序。


## Step 06 第二部分：边界与碰撞

- 六个大物件使用贴地顶点切片圆：树取地面以上 0–0.5，其他取 0–0.3；不使用树冠包围盒。圆心来自切片本身，位置仍读取 main.js 的 placement；加载后 console.table 打印实测值。
- `src/island-collision.js` 顶部 `OBSTACLE_RADII` 可逐项调整；身体半径 `BODY_RADIUS=0.46` 不含尾巴，岛边额外留白 `BOUNDARY_MARGIN=0.04`，总内缩 0.50。
- 圆碰撞和岛的 outline 边界都保留切向移动；地面与跳跃共用同一水平约束。花草、踏脚石不阻挡；不支持跳上物件。
- B 切换线框，默认隐藏：红色物件圆，蓝色身体圆，绿色原岛边，黄色中心可达边界。
- `node tests/step06-collision.mjs` 检查多角度阻挡、斜向滑动、边界与随机移动；`node tests/step06.mjs` 包含实际角色跳跃时的边界集成检查。
- 开发预览 `?record=1&collision=1` 的 15 秒录屏是五段自动布置测试点的脚本演示，使用正式控制器，并在录像中标注；不是手动连续走完的路线。普通页面不自动移动。
- 圆形阻挡是保守近似，树根间与窝内不会作为可进入区域；真实手机与所有浏览器尚未验证。
