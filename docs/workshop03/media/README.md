# Workshop 03 手动录制

运行 npm run dev，打开 http://127.0.0.1:5173/?gif=<编号>。

- w03-s04-idle：6 秒，白天全景待机。
- w03-s05-wasd：12 秒，W → 转镜头后 W → W+D → Shift 跑 → 停下。
- w03-s06-jump-side：8 秒，侧面原地跳两次，再边走边跳一次。
- w03-s07-nest-rest：18 秒，走到窝 → E → 趴下 → 侧面看 → W 起身跳出。
- w03-s07-lantern-night：14 秒，走到灯笼 → E → 看夜景 → 走两步。

先等模型加载并手动准备机位，再点击开始。共享选择器中选当前标签页，不要选窗口或屏幕。preferCurrentTab 只是提示，请自行核对标签页。授权后倒数三秒，控件隐藏后开始录制，到时自动下载 WebM。倒数中再次点击取消；录制中按钮隐藏，按 Esc 或浏览器“停止共享”提前结束。浏览器可能要求允许下载。

工具只请求视频，不录音，不移动角色或设置镜头；录整张网页，包含提示及小卡片。仅开发模式且有效编号显示，生产构建不包含录制器。

将下载的 WebM 放入本目录 raw/，在项目根目录执行：

```sh
node scripts/make-gifs.mjs
```

脚本检查 ffmpeg/ffprobe，不自动安装。两步调色板，12 fps / 960 宽，保持比例；超过 8 MiB 重试 10 fps / 800 宽，仍超限会报告。打印实际时长、尺寸、字节数和 MiB。同名 GIF 会被替换，WebM 保留。

浏览器共享、下载和真人操作须人工验证；合成测试视频不属于教程成果。
